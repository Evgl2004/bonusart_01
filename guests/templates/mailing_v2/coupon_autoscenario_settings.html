Отбор гостей по заведению включён, поэтому купон выбирается по выбранному заведению отбора. Технически используется безопасный режим «Последнее заведение».
Последнее заведение - один купон по последнему заведению гостя, затем запасное правило «Вся сеть».
Все посещённые заведения - отдельный купон по каждому заведению из таблицы, где гость уже был хотя бы один раз.
Любимое заведение - один купон по заведению с наибольшим числом заказов; при равенстве выбирается более свежий визит.
