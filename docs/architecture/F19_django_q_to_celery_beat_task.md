# F19. Точка развития: миграция Django Q -> Celery + Celery Beat

## Статус
Запланировано (без детализации на текущем этапе).

## Назначение
Зафиксировать отдельную задачу развития проекта:
1. перейти с `Django Q` на `Celery` для фоновых задач;
2. перейти с текущего расписания `Django Q schedule` на `Celery Beat`.

## Границы текущей фиксации
1. В этом документе намеренно нет детального технического плана.
2. Детализация выполняется отдельным шагом после завершения текущего контура доработок и первичного запуска.

## Причина отложенной детализации
1. Приоритет текущего этапа: завершить действующий план, выполнить запуск и получить «живой» результат.
2. После стабилизации текущего контура будет подготовлен точный поэтапный план миграции без риска регрессий.

## Критерий готовности к старту F19
1. Текущий контур F18 завершён и прошёл smoke-проверки.
2. Подтверждена базовая работоспособность обработки webhook, универсальной очереди и OLAP-контура.
