# Импорт аудитории кампании из Excel

## Назначение

На странице «Аудитория» оператор перед загрузкой Excel-файла выбирает, гостей
с какими каналами необходимо добавить в кампанию. Отбор использует штатный
планировщик доставки, поэтому правила импорта совпадают с правилами фактической
постановки сообщений в очередь.

## Режимы импорта

### Гости новых ботов

В кампанию добавляются гости, для которых штатный планировщик нашёл разрешённую
активную привязку к одному из активных ботов, выбранных в кампании. Этот режим
используется по умолчанию и сохраняет совместимость со старыми запросами,
которые не передают новый параметр выбора аудитории.

### Исторические Telegram-гости (старый бот)

В кампанию добавляются гости с доступным историческим Telegram-каналом. Канал
должен иметь состояние «можно отправлять», а в кампании должен быть выбран
активный Telegram-бот. Гость, зарегистрированный в новом контуре, не относится
к исторической аудитории независимо от текущего согласия на рассылку.

Если в Excel явно заполнен столбец `telegram_external_id`, его значение может
использоваться как резервный исторический адрес для гостя, которому штатный
планировщик не нашёл другого канала. Резервный адрес не используется, если у
гостя есть активная новая привязка или регистрация в новом контуре: запрет на
рассылку через новый бот нельзя обойти значением из файла.

### Все гости с доступным каналом отправки

В кампанию добавляется объединение двух предыдущих групп. Ограничение
уникальности пары «кампания + гость» не позволяет создать повторную строку,
если один и тот же файл загружается повторно.

## Показатели отчёта импорта

- «Найдено гостей в базе» — число телефонов, сопоставленных с `Guest`.
- «Доступна отправка через новые боты» — число гостей с новым разрешённым каналом.
- «Доступна отправка через исторический Telegram» — число гостей с историческим каналом.
- «Всего гостей с доступным каналом» — объединение двух групп без дублей.
- «Найдены, но нет доступного канала» — гости `Guest`, которым планировщик не нашёл маршрут.
- «Есть доступный канал, но не входят в выбранную группу» — гости другой доступной группы.
- «Уже были в кампании» — гости выбранной группы, ранее добавленные в эту кампанию.

## Проверка

Целевые и регрессионные тесты запускаются только штатным скриптом из корня
проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_pytest.ps1 guests/tests/test_mailing_import_audience.py guests/tests/test_mailing_delivery_targets.py guests/tests/test_mailings_v2_views.py
```

Для полной регрессии приложения:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_pytest.ps1 guests/tests
```
