## 1. Итог команды vtelemax

Текущая производственная логика Telegram, VK и MAX совместима с новым набором. Ссылочная кнопка не является обратным действием SAGUR, не создаёт событие vtelemax → SAGUR и при удалении оценки сохраняется вместе с кнопкой «Меню».

Версия 2 служебного JSON и пакетный контракт событий не меняются. Производственный код vtelemax для согласованного формата дорабатывать не требуется.

## 2. Telegram

Проверены `TelegramSagurInteractionFilter`, `_perform_rating_action` и общий механизм `remove_sagur_rating_buttons_from_rows`.

- Фактическая клавиатура читается из `callback.message.reply_markup.inline_keyboard`.
- Служебный JSON извлекается только из `callback_data`.
- У URL-кнопки нет `callback_data`, поэтому она не считается действием SAGUR и не создаёт событие.
- После оценки сохраняются исходный объект URL-кнопки, подпись, адрес, поддерживаемый стиль и отдельный ряд.
- Кнопка `m`, текст и вложения сообщения сохраняются.

## 3. VK

Проверены `VkSagurInteractionRule`, `_button_payload`, `build_vk_keyboard_without_rating`, `_fetch_source_message` и `_perform_rating_action`.

- Фактическое сообщение читается через `getByConversationMessageId`.
- Служебный JSON разбирается только у кнопок `action.type=callback`.
- Кнопка `action.type=open_link` не считается действием SAGUR и сохраняется целиком, включая тип, подпись, адрес и отдельный ряд.
- После удаления пустого ряда оценки ссылка становится первым рядом, а `m` — вторым.
- Для текстовых сообщений поддерживаются вложения `photo`, `video`, `audio`, `doc`, `wall`.
- Иные типы, например `sticker`, требуют отдельного согласования: текущий код безопасно прекращает редактирование, чтобы не потерять исходное содержимое.

## 4. MAX

Проверены `MaxSagurInteractionFilter`, `_button_payload`, `build_max_attachments_without_rating` и `_perform_rating_action`.

- Фактическая клавиатура извлекается из `event.message.body.attachments`.
- Служебная нагрузка читается только у кнопок `type=callback`.
- Кнопка `type=link` не считается действием SAGUR и сохраняет тип, подпись, адрес и отдельный ряд.
- При редактировании изменяется только массив рядов встроенной клавиатуры; текст, прочие вложения и `m` сохраняются.
- Для обычного текстового сообщения производственный код менять не требуется.
- Непустая разметка текста `markup` требует отдельного согласования: текущий код безопасно прекращает редактирование, чтобы не потерять форматирование.
