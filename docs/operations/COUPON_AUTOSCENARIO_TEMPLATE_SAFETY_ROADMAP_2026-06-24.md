# Roadmap: защита шаблонов купонных автосценариев

## Контекст
На странице создания пользовательского купонного автосценария оператор сейчас всегда
создаёт новый `MessageTemplate`. Если в тексте забыть `{coupon_code}`, сценарий может
выдать купон, но гость не увидит код в сообщении. Также перед переводом сценария в
`Пилот` или `Активен` нет отдельной защиты от отсутствующих купонных правил.

## Цель
Сделать создание и запуск пользовательских купонных автосценариев безопаснее:
использовать существующие шаблоны без дублей, блокировать сценарии без `{coupon_code}`,
показывать предпросмотр сообщения и не разрешать пилот/боевой режим без правил купонов.

## Объём доработки
1. Добавить на `/mailings-v2/scenarios/coupons/new/` выбор режима шаблона:
   - создать новый шаблон;
   - использовать существующий активный шаблон.
2. При выборе существующего шаблона привязывать его к новому `NotificationScenario`
   без создания копии.
3. Для купонного автосценария требовать точный плейсхолдер `{coupon_code}`:
   - при создании нового шаблона;
   - при выборе существующего шаблона;
   - при переводе сценария в `Пилот` или `Активен`.
4. Подсвечивать похожие, но неверные варианты:
   - `{{ coupon_code }}`;
   - `{ coupon_code }`;
   - `[coupon_code]`.
5. При создании нового шаблона добавлять в описание служебную пометку
   `Создано для купонного автосценария: <code>`.
6. На странице настроек показывать предпросмотр сообщения с примерными значениями:
   - `first_name = Анна`;
   - `days_without_visits = 30`;
   - `coupon_code = TEST123`.
7. Блокировать сохранение `Пилот`/`Активен`, если нет ни одного активного купонного
   правила с серией купонов и нет заполненной резервной серии.

## Тестовое покрытие
1. Создание сценария с новым шаблоном и `{coupon_code}` проходит.
2. Создание сценария с существующим шаблоном проходит и не создаёт дубль шаблона.
3. Создание сценария без `{coupon_code}` блокируется.
4. Создание сценария с `{{ coupon_code }}` или `{ coupon_code }` блокируется понятной ошибкой.
5. Выбор существующего шаблона без `{coupon_code}` блокируется.
6. Перевод в `Пилот` без активного правила/резервной серии блокируется.
7. Перевод в `Пилот` с активным правилом и корректным шаблоном проходит.
8. Перевод в `Пилот` с шаблоном без `{coupon_code}` блокируется.
9. Страница настроек показывает предпросмотр с подставленным `TEST123`.
